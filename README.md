# Orange Law

Bitcoin power-law tracker (USD / CAD / gold), Giovanni Santostasi model.

**Live:** [orangelaw.ca](https://orangelaw.ca)

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Hosted on Vercel from this repo. Production domain is `orangelaw.ca`.
A push to `main` rebuilds automatically.

Price quotes use Coinbase / Kraken / Bank of Canada. No database required for the public site.
